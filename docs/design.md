# FlyLab design

更新日: 2026-09-17

## 1. 目的

MaleCNS v1.0 と、それを利用した Stonkfly の実験に着想を得て、ハエの神経回路らしい情報伝播をブラウザ上で観察・比較できる実験環境を作る。

この初版の目的は「MaleCNS 全体を忠実に再現すること」ではない。16.67 万ニューロン、約 2,560 万接続の全保持シミュレーションには大きなデータと計算資源が必要なため、まず次を満たす縮約モデルを提供する。

- 入力、介在、記憶、運動、ドーパミンの各集団を持つ小規模なスパイキング回路
- 刺激と神経活動と行動出力の因果関係を一画面で追える
- 可塑性の有無、刺激条件、乱数シードを変えて比較できる
- 実験結果を端末内に記録し、CSV として持ち出せる
- 生物学的事実、工学的仮定、未実装範囲を明示する

## 2. 調査から得た前提

- `natverse/malecns` は MaleCNS データへアクセスする R パッケージであり、シミュレータ本体ではない。
- 公開スナップショットは `male-cns:v1.0`。neuPrint で接続や注釈にアクセスできる。
- Stonkfly は 166,700 ニューロンと約 25.6M 接続を保持し、視覚入力、固定の読み出し、人工的な報酬信号、候補となる可塑性則を組み合わせている。
- Stonkfly 自身も、回路が利益を上げる方法を学習したとは実証していない。FlyLab でも挙動を生物学的能力の証拠として扱わない。

## 3. 初版の体験

### 観察できるもの

- 8 集団: 左右視覚、嗅覚、統合、記憶、左右運動、ドーパミン
- 個々のニューロンの膜電位と発火
- 集団ごとの発火率
- 左右運動集団の差から得る旋回方向と前進量
- 可塑性が有効なときの記憶→運動シナプス強度

### 操作できるもの

- 左右の光強度
- 匂い強度
- 報酬刺激
- 神経ノイズ
- 可塑性の有効/無効
- シミュレーション速度
- 開始、一時停止、1 ステップ、リセット
- 乱数シード

### 実験プリセット

1. 光走性: 左右の光差が旋回出力にどう表れるか
2. 匂いと報酬: 匂い入力と報酬を同時提示し、可塑性の変化を見る
3. 感覚競合: 光と匂いの入力が競合する状態を観察する
4. ノイズ耐性: 同一刺激でノイズ量だけを変える

### 記録

- 実験名、シード、刺激、可塑性、経過時間、発火数、最終行動、平均発火率、シナプス変化を保存
- ブラウザのローカルストレージへ保存
- 1 件ずつ削除、全件消去、CSV エクスポート

## 4. シミュレーションモデル

### ニューロン

離散時間の leaky integrate-and-fire (LIF) モデルを使う。

```text
V(t+1) = V(t) + leak * (rest - V(t)) + input + noise
V >= threshold のとき発火し、V = reset
```

- 1 ステップは 20 ms
- 発火後に短い不応期を設ける
- 初版は 84 ニューロン程度を描画・計算する
- 擬似乱数生成器をシード固定し、条件の再現性を確保する

### 接続

- 集団内と集団間を決定的に生成する疎な有向グラフ
- 重みは興奮性または抑制性
- 視覚→統合→運動、嗅覚→記憶→運動を主要経路とする
- 左右交差抑制により旋回差を作る

### 可塑性

教育用途の簡略化された三因子則を使う。

```text
eligibility += pre_spike * post_activity
weight += learning_rate * reward_signal * eligibility
```

- 対象は記憶→運動の一部接続のみ
- 重みには上下限を設ける
- 「実験的な工学モデル」であり、MaleCNS の学習機構を忠実に再現したものではないと画面に表示する

### 行動の読み出し

- 右運動発火率 − 左運動発火率を旋回量に変換
- 左右運動発火率の合計を前進量に変換
- これは人工的な読み出し規則であり、特定細胞の生物学的意味を主張しない

## 5. 画面設計

神経科学の観測装置と実験ノートを合わせた、暗色で高コントラストな一画面構成とする。

```text
┌──────────────────────────────────────────────────┐
│ FlyLab / model scope                    status   │
├──────────────┬────────────────────────┬──────────┤
│ stimulus     │ neural field           │ readout  │
│ controls     │ animated graph         │ fly path │
│ presets      │ timeline / legend      │ metrics  │
├──────────────┴────────────────────────┴──────────┤
│ experiment notebook / saved comparisons          │
└──────────────────────────────────────────────────┘
```

- 主要色: 墨色、青緑、蛍光ライム、暖色の報酬色
- 数値は等幅、説明は読みやすいサンセリフ
- Canvas は装飾ではなく、発火と信号伝播を示す観測面として使う
- モバイルでは操作→観測→結果→記録の順に縦積み
- キーボード操作、十分なフォーカス表示、色以外の状態表示を用意する

## 6. 技術構成

- React + TypeScript + Vinext/Vite
- シミュレーション計算は UI から分離した純粋 TypeScript モジュール
- Canvas 2D で神経回路と軌跡を描画
- React state で操作と 20 Hz 以下の表示更新を管理
- localStorage は実験記録だけに使用
- サーバー、認証、外部 API、実取引は使用しない

## 7. 実装計画

1. シミュレーション型、シード乱数、回路生成、LIF 更新、可塑性、読み出しを実装
2. 実験プリセットと集計関数を実装
3. 操作パネル、回路 Canvas、時系列チャート、行動表示を実装
4. 実験ノート、ローカル保存、CSV 出力を実装
5. レスポンシブ表示とアクセシビリティを整える
6. 決定性、リセット、可塑性境界、記録形式をテスト
7. ビルドと表示内容を検証し、`docs/implementation.md` と README を更新

## 8. 完了条件

- 4 プリセットを選択して開始、一時停止、ステップ、リセットできる
- 同じシードと条件で同じ結果になる
- 回路活動、発火率、旋回出力、軌跡をリアルタイム表示できる
- 可塑性の有無で重み変化を比較できる
- 実験を保存・削除・CSV 出力できる
- モデルの範囲と注意事項が UI と文書の両方にある
- `npm test`、`npm run lint`、`npm run build` が成功する
