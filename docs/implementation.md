# 実装記録

更新日: 2026-09-17

## 実装した内容

### シミュレーション

- シード付き xorshift 擬似乱数生成器
- 84 ニューロン、8 集団の決定的な回路生成
- 興奮性・抑制性シナプスを含む疎な有向グラフ
- 20 ms 刻みの leaky integrate-and-fire 更新
- 2 ステップの簡易不応期
- 集団発火率の指数移動平均
- 記憶→運動接続だけを対象にした適格度トレースと報酬依存更新
- 重みの上下限
- 左右運動集団の差と合計による旋回・前進読み出し
- 軌跡と時系列の上限付き履歴

### UI

- 刺激条件、可塑性、SEED、速度の操作
- 光走性、匂いと報酬、感覚競合、ノイズ耐性のプリセット
- 回路活動、発火中の接続、集団発火率、運動軌跡の Canvas 描画
- 開始、一時停止、1 ステップ、リセット
- 実験結果の localStorage 保存
- 記録の削除、全件消去、CSV エクスポート
- モデルの範囲と人工的な読み出し規則の常時表示
- レスポンシブ表示、フォーカス表示、reduced motion 対応
- サイト内容に合わせた Open Graph / X 用プレビュー画像

## 設計からの調整

- 設計中の「7 集団」は、左右視覚と左右運動をそれぞれ独立集団として数えると 8 集団になるため修正した。
- 可塑性の対象は初版で観察しやすいよう、記憶→左右運動の候補接続に限定した。
- 実データのインポートは、neuPrint 認証と大規模前処理を必要とするため初版には含めなかった。
- 外部 API、暗号資産、市場データ、実取引は安全性と実験目的の分離のため含めなかった。

## 既知の制約

- 回路は機能を説明する縮約モデルであり、MaleCNS の実接続を使っていない。
- シミュレーションは UI スレッド上で動くため、ニューロン数を大幅に増やすには Web Worker などが必要。
- localStorage の記録は同じブラウザ・端末にだけ保存される。
- 行動出力は人工的な読み出しであり、実際のハエの運動を予測しない。
- 可塑性則は学習能力や課題性能を保証しない。
